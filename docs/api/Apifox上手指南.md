# Apifox 上手指南（零基础版 · 第 3 周任务用）

> 你要做的事一句话：把仓库里 `api/openapi.json` 导入 Apifox，26 个接口自动出现，开 Mock，把项目共享给前端队友。全程约 20 分钟，不需要手写任何接口。

---

## 第一步：安装与注册（5 分钟）

1. 打开 https://apifox.com ，下载 Windows 版安装；
2. 微信扫码注册登录；
3. 第一次打开会让你"新建团队"——团队名填：`失物招领平台项目组`。

## 第二步：导入接口（2 分钟，核心步骤）

1. 团队里点 **「新建项目」** → 项目名：`校园失物招领智能匹配平台`；
2. 进入项目后，点左上角 **「项目设置」（齿轮图标）→「导入数据」**；
3. 选择 **「OpenAPI/Swagger」** 格式 → 把仓库里的 `api/openapi.json` 文件拖进去；
4. 导入方式选 **「智能合并」**，点确定；
5. 回到左侧接口目录，你会看到按"认证/用户/基础数据/信息/匹配/认领/消息/后台"分好组的 **26 个接口**，每个接口的参数、示例数据都在。

> 到这里，"设计接口"这件事已经做完了。这些接口是照着我们数据库设计（10 张表）逐个定义的，不是随便编的。

## 第三步：验证 Mock 能跑（2 分钟）

1. 随便点一个接口，比如 **「登录」**；
2. 切到 **「快捷请求」** 标签页，直接点 **「发送」**；
3. 看到返回 `"code": 0, "token": "eyJhbGc..."` 就说明 Mock 正常——**Apifox 自动生成 Mock 数据，不用配**。

## 第四步：把项目共享给前端队友（3 分钟）

1. 项目内右上角 → **「邀请成员」**→ 生成邀请链接发群里；
2. 给前端队友的权限选 **「可编辑」** 也没关系，主要是能看；
3. 告诉前端队友：**每个接口文档页右上角有「复制 Mock URL」，前端开发的 baseURL 就填这个**。

## 第五步（可选）：开启云端 Mock

本地 Mock 只能你自己电脑用。要让前端队友也能调 Mock：

1. 项目设置 → **「功能设置」→「Mock 设置」**；
2. 打开 **「云端 Mock」**；
3. 把云端 Mock 的 URL（形如 `https://mock.apifox.com/m1/xxxxxx`）发给前端。

## 你这周还要做的两件事（真正的"设计"工作）

导入只是起点，本周结束前完成：

1. **通读一遍 26 个接口**，重点检查这几个业务规则是否符合你的理解，不对就改：
   - 详情接口 `GET /api/items/{id}`：`contactVisible` 字段控制联系方式是否可见（隐私设计）；
   - 发布接口：`type=FOUND` 时 `hiddenFeatures` 必填（防冒领设计）；
   - 认领流程的 5 个接口串起来：申请 → 核验 → 取核销码 → 扫码核销 → 完成；
2. **每个接口补 Mock 示例**：导入时大部分接口已带示例（example），对没有示例的（如"我发布的信息列表"），照抄同类接口的格式补上——前端队友下周要靠这些数据写页面。

## 常见疑问

**Q：接口后面要改怎么办？**
A：直接在 Apifox 里改，改完左侧会有变更标记，前端能看到。后端开发时就按 Apifox 上的最新版实现——**Apifox 是唯一事实来源**，不要群里口头改接口。

**Q：Mock 数据和真后端数据格式不一样怎么办？**
A：不会不一样——后端第 5 周开发时就是照着这份契约返回数据的。第 8 周联调时，前端只需把 baseURL 从 Mock 地址换成后端地址（`http://localhost:8080`），代码一行不用改。

**Q：这个 openapi.json 以后还能重复导入吗？**
A：能。你在文件里改了接口 → 再导入一次选"智能合并"，Apifox 会同步更新。
